### How it gets built

- **Claude Code** — My daily builder. Writes the code, I decide what ships
- **GPT, Gemini and Mistral** — The second opinions: bug hunts, research and translations
- **A reference library of 116 apps** — Before designing a screen, I look at how the best apps already solved it
- **Real mocks only** — Every design is tried in the real app on the simulator, never in a drawing tool
- **Nightly test run** — The full suite runs while I sleep, so mornings start green
